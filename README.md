# Yasmin.lab.rez — электронды резюме-кітап

Төрехан Ясминнің электронды резюме-кітабы. Жоба фронтенд (HTML, CSS, JavaScript) және бэкенд (Java) бөлімдерінен тұрады.

**Сайттың онлайн нұсқасы (GitHub Pages):** https://9hbvhjhvvc-lgtm.github.io/Yasmin.lab.rez/

## Қолданылған технологиялар

| Технология | Файл | Қызметі |
|---|---|---|
| HTML5 | `index.html`, `messages.html` | беттердің құрылымы |
| CSS3 | `style.css`, `messages.css` | кітаптың дизайны, парақ аудару анимациясы, мобильді нұсқа |
| JavaScript | `script.js`, `messages.js` | парақтау, мазмұн, байланыс формасы, хабарламаларды жүктеу |
| Java | `Server.java` (`Server.class`) | HTTP-сервер: беттерді береді, формадан келген хабарламаны `data/messages.txt` файлына сақтайды |

## Жоба құрылымы

```
Yasmin.lab.rez/
├── index.html      # кітаптың негізгі беті
├── messages.html   # келген хабарламалар беті
├── style.css       # кітаптың стильдері
├── messages.css    # хабарламалар бетінің стильдері
├── script.js       # парақтау және байланыс формасы
├── messages.js     # хабарламаларды серверден алу
├── Server.java     # Java сервері (бастапқы код)
├── Server.class    # компиляцияланған сервер (Java 8+)
├── start.bat       # Windows-та іске қосу
└── start.sh        # Linux / macOS-та іске қосу
```

## Жұмыс принципі

1. Java сервері `http://localhost:8080` мекенжайында іске қосылады.
2. Сервер HTML, CSS және JS файлдарын браузерге береді.
3. «Байланыс» бетіндегі форма толтырылып, «Жіберу» басылғанда, JavaScript мәліметті JSON түрінде `/api/messages` мекенжайына POST сұранысымен жібереді.
4. Java сервері өрістерді тексеріп, хабарламаны `data/messages.txt` файлына жазады.
5. Барлық хабарламалар `http://localhost:8080/messages.html` бетінде көрінеді (GET `/api/messages`).

## Іске қосу

**Windows:** `start.bat` файлын екі рет басыңыз. Браузерде `http://localhost:8080` ашылады.

**Қолмен:**

```
javac -encoding UTF-8 -d . Server.java
java -cp . Server
```

Компьютерде Java 8 немесе одан жаңа нұсқасы болуы керек (`java -version`).

> GitHub Pages тек статикалық беттерді көрсетеді, сондықтан онлайн нұсқада кітап толық жұмыс істейді, ал байланыс формасы тек Java сервері іске қосылғанда (локальді) жұмыс істейді.
